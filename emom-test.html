EMOM rehearsal

The real screen, driven by a clock this page controls. This is the only way to check a clock-led day without standing in a gym for half an hour: the failure modes are all about time passing, so tapping through it proves nothing. Run it at 60x and a thirty minute block takes thirty seconds.
Everything below comes from js/emom.js and js/emom-view.js, the same two modules the logging screen mounts. Nothing here reimplements the view, so a rehearsal that looks right is the real screen looking right.
Nothing is written. No storage, no adapter, no session. The rows column shows what the logging screen WOULD have appended at each window boundary.
